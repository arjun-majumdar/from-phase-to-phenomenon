This repository contains the official implementation accompanying our ECCV 2026 paper:

> **From Phase to Phenomenon: Self-Supervised Learning of Subsurface Scattering with Minimal Phase-shift Inputs**

The project introduces a complete pipeline for learning subsurface-scattering representations directly from phase-shift profilometry (PSP) measurements. The repository is organized into three sequential stages. Each stage contains its own detailed `README.md` with dataset preparation, usage instructions, configuration options, and examples.

> ⚠️ **Important:** Execute the stages **in order** — the output generated by each stage is required by the next.

## 🗺️ Repository Overview

| Stage | Description |
|:---:|---|
| 🔦 **[1. 3D Scanning](1_ThreeD_Scanning/README.md)** | Generate phase-shift projector patterns, capture them using a calibrated projector-camera setup, unwrap phase maps, and recover dense camera-to-projector correspondences. |
| 🧠 **[2. SSL Pretraining](2_SSL_Pretraining/README.md)** | Pretrain a SimSiam encoder on PSP patches using both conventional augmentations and our proposed PSP-aware augmentations. |
| 🎨 **[3. Post-SSL Reconstruction](3_Post_SSL_Pretraining/README.md)** | Freeze the pretrained encoder, train a decoder to predict per-point subsurface-scattering footprints, and visualize reconstructed relighting results. |

```text
Structured-Light Acquisition
            │
            ▼
 Self-Supervised Pretraining
            │
            ▼
Subsurface-Scattering Reconstruction
            │
            ▼
 Visualization & Relighting
```

## 🔗 Pipeline Dependencies

| Stage | 📥 Input | 📤 Output |
|---|---|---|
| 🔦 **3D Scanning** | Captured PSP images (`.exr`) and object segmentation mask | Unwrapped phase maps, dense correspondences, valid masks, stacked PSP inputs |
| 🧠 **SSL Pretraining** | PSP patches extracted from valid object regions | SimSiam pretrained encoder checkpoint |
| 🎨 **Post-SSL Reconstruction** | Frozen encoder + ground-truth scattering footprints | Trained decoder, reconstructed scattering footprints, relit renderings and PCA visualizations |

> 🎯 The object mask generated during Stage 1 ensures that only valid object pixels are used during SSL training, preventing background regions from contaminating the learned representation.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/<username>/from-phase-to-phenomenon.git
cd from-phase-to-phenomenon
```

Install the project dependencies:

```bash
pip install -r requirements.txt
```

> ⚠️ **Note:** Install a CUDA-enabled PyTorch version compatible with your system. Instructions are available at <https://pytorch.org/get-started/locally/>.

## 🚀 Getting Started

Follow the pipeline sequentially:

1. 🔦 **[3D Scanning](1_ThreeD_Scanning/README.md)**
   - Generate structured-light patterns
   - Capture object images
   - Compute phase maps and correspondences

2. 🧠 **[SSL Pretraining](2_SSL_Pretraining/README.md)**
   - Train the SimSiam encoder
   - Evaluate learned representations

3. 🎨 **[Post-SSL Reconstruction](3_Post_SSL_Pretraining/README.md)**
   - Train the decoder
   - Predict scattering footprints
   - Generate relighting visualizations
