Learning Subsurface Scattering from Phase-Shift Profilometry

A three-stage pipeline: scan objects with structured light, self-supervise a representation of their subsurface light transport, then decode and visualize per-point scattering. Start here, then dive into each stage.

Pipeline at a glance

The project is organized as three sequential stages. Each lives in its own sub-directory with a dedicated, detailed README. Run them in order — the outputs of one stage are the inputs of the next.

1

3D Scanning

Generate phase-shift profilometry (PSP) projector patterns, capture them on a projector–camera rig, and recover unwrapped phase maps + dense camera-to-projector pixel correspondences.

Open stage 1 → 2

SSL Pretraining

Self-supervised SimSiam pretraining of an encoder on object patches — comparing standard ImageNet-style augmentations against our novel PSP augmentations.

Open stage 2 → 3

Post-SSL: Decode & Visualize

Freeze the pretrained encoder, train a decoder to predict per-point subsurface-scattering footprints, then render relit outputs and PCA-RGB feature maps.

Open stage 3 →
scan  →  pretrain  →  decode / visualize

How the stages connect

StageConsumesProduces
1 — 3D Scanning Captured PSP .exr images + a SAM object mask Stacked PSP inputs, unwrapped phase maps, camera→projector correspondences, valid-point masks
2 — SSL Pretraining Stacked PSP patches (on-object only, via the mask) A SimSiam-pretrained encoder checkpoint
3 — Post-SSL Frozen encoder + GT subsurface-scattering footprints Trained decoder, relit renders, PCA-RGB visualizations

The SAM mask from stage 1 ensures stage 2 only ever sees on-object patches, so the encoder isn't poisoned by background pixels.

Getting started

Install everything at once from the combined top-level requirements:

pip install -r requirements.txt

Install a CUDA-enabled PyTorch build that matches your system's CUDA version (see pytorch.org/get-started/locally); the default PyPI wheel may be CPU-only.

Then open the stage you need:

  • 1_ThreeD_Scanning — PSP patterns & phase unwrapping
  • 2_SSL_Pretraining — SimSiam self-supervised pretraining
  • 3_Post_SSL_Pretraining — decoder training & visualization
